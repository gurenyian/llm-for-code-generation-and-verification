你是一个符号执行专家。请为函数 `PathIsRelativeW` 生成 ODA（On-Demand Abstraction）规约。

## 背景知识

ODA 的目的是为复杂的依赖函数生成简化的 stub，使得 KLEE 可以高效地进行符号执行。

### Stub 的类型

1. **symbolic_return**: 符号化返回值
   - 适用于：返回值影响控制流的函数
   - 示例：`lstrlenW` 返回长度，用于 `if (len > 0)` 判断

2. **symbolic_output**: 符号化输出参数
   - 适用于：通过指针参数返回结果的函数
   - 示例：`GetSystemTime` 通过指针参数返回时间

3. **noop**: 空操作
   - 适用于：返回值不影响控制流的函数
   - 示例：日志函数、调试函数

### 约束的原则

1. **边界情况**：NULL 指针、空字符串、0 值等
2. **合理范围**：返回值的最小/最大值（如字符串长度 0-260）
3. **充分条件**：确保能触发目标函数的所有分支

### 步骤 1: 分析影响

对于每个依赖函数，判断：
- 它的返回值是否出现在谓词中？
- 它的返回值是否被赋值给变量，然后用于条件判断？
- 它是否有副作用（修改全局状态、输出参数）？

### 步骤 2: 选择抽象类型

- 如果返回值影响控制流 → `symbolic_return`
- 如果有输出参数 → `symbolic_output`
- 如果都不影响 → `noop`

### 步骤 3: 生成约束

对于 `symbolic_return` 类型，生成约束代码（C 语言）：

```c
// 1. 处理边界情况
if (param == NULL) return ERROR_VALUE;

// 2. 创建符号变量
TYPE ret;
klee_make_symbolic(&ret, sizeof(ret), "function_name_ret");

// 3. 添加合理范围约束
klee_assume(ret >= MIN && ret <= MAX);

// 4. 添加充分条件约束（确保能触发所有分支）
// 例如：如果谓词是 "len > 0"，需要确保 len 可以是 0 和 >0
if (ret > 0) klee_assume(param[0] != 0);  // 非空字符串

// 5. 返回
return ret;
```

static HRESULT parse_path(BSTR path, BSTR *provider, BSTR *server, BSTR *dn)
{
    WCHAR *p, *p_server;
    int server_len;

    *provider = NULL;
    *server = NULL;
    *dn = NULL;

    if (wcsnicmp(path, L"LDAP:", 5) != 0)
        return E_ADS_BAD_PATHNAME;

    *provider = SysAllocStringLen(path, 4);
    if (!*provider) return E_OUTOFMEMORY;

    p = path + 5;
    if (!*p) return S_OK;

    if (*p++ != '/' || *p++ != '/' || !*p)
    {
        SysFreeString(*provider);
        return E_ADS_BAD_PATHNAME;
    }

    p_server = p;
    server_len = 0;
    while (*p && *p != '/')
    {
        p++;
        server_len++;
    }
    if (server_len == 0)
    {
        SysFreeString(*provider);
        return E_ADS_BAD_PATHNAME;
    }

    *server = SysAllocStringLen(p_server, server_len);
    if (!*server)
    {
        SysFreeString(*provider);
        return E_OUTOFMEMORY;
    }

    if (!*p) return S_OK;

    if (*p++ != '/' || !*p)
    {
        SysFreeString(*provider);
        SysFreeString(*server);
        return E_ADS_BAD_PATHNAME;
    }

    *dn = SysAllocString(p);
    if (!*dn)
    {
        SysFreeString(*provider);
        SysFreeString(*server);
        return E_OUTOFMEMORY;
    }

    return S_OK;
}
